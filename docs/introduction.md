# HCAE

**Himrich's CPU Architecture and Emulator**

HCAE is an open-source functional emulator for Himrich's CPU Architectures (HCAs).

Unlike CPU-only emulators, HCAE is designed to emulate an entire machine, encompassing the CPU and its surrounding hardware.

## HCA

**Himrich's CPU Architecture**

An HCA is a little-endian RISC architecture that targets simplicity and speed.

Here are the current HCAs:

 - [hca32v1](hca/32v1/architecture.md): The first 32-bit specification.
