# Himrich's CPU Architecture and Emulator (HCAE)

HCAE is a functional emulator for Himrich CPU Architectures (HCAs).

This project was created primarily for entertainment and educational purposes.

(Big-endian hosts are not supported)

# C/C++ API

The C/C++ API is in [here](api.md).

# Himrich's CPU Architecture (HCA)

HCA is a little-endian RISC architecture designed with simplicity and efficiency in mind.

- [hca32v1](hcas/32v1/architecture.md): The first 32-bit HCA specification.
